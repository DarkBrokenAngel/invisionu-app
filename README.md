## ❓ The Problem

**inVision U** is an innovative university with 100% scholarships funded by **inDrive**, launched in Kazakhstan to educate future leaders, entrepreneurs, and project builders.

Today, the admissions committee manually evaluates every application, essay, and video. This creates **4 critical problems:**

| Problem | Impact |
|---------|--------|
| 🔇 Talented applicants can't "sell themselves" | Real potential is invisible behind poor presentation |
| 📋 Standard forms miss leadership signals | Strong candidates filter themselves out before applying |
| 🤖 Generative AI blurs authentic voice | Essays become unreliable assessment tools |
| 📈 Scale kills quality | More applicants = shallower individual review |

---

## 💡 Our Solution

**InVisionU** is an AI-powered screening platform that evaluates candidates across **4 dimensions** while keeping the committee as the final decision-maker.

```
                          ┌─────────────────────────┐
                          │    CANDIDATE INPUT       │
                          │  Interview · CV · Letter │
                          └────────────┬────────────┘
                                       │
                          ┌────────────▼────────────┐
                          │   AI SCORING ENGINE      │
                          │  Multilingual NLP (EN/   │
                          │  RU/KZ) · 4 Dimensions   │
                          └────────────┬────────────┘
                                       │
                    ┌──────────────────▼──────────────────┐
                    │  EXPLAINABLE RESULTS & RANKING      │
                    │  Score Breakdown · Feedback · Radar  │
                    └──────────────────┬──────────────────┘
                                       │
                          ┌────────────▼────────────┐
                          │  ADMIN PANEL (HUMAN)     │
                          │  Approve · Reject ·      │
                          │  Waitlist                 │
                          └─────────────────────────┘
```

> ⚠️ **AI does NOT make autonomous decisions.** The final word always remains with the committee.

## 🧪 Scoring Engine

### Algorithm

```
Score = Base(30)
      + Length Bonus     (up to 30 pts)
      + High Keywords    (×8 pts each)
      + Medium Keywords  (×4 pts each)
      + Sentence Variety (+10 pts max)
      + Specificity      (+7 pts max)
      ± Variance         (±2 pts)
      → Clamped [20, 100]
```

### Weights

| Component | Weight | Rationale |
|-----------|--------|-----------|
| AI Interview | **40%** | Real-time dialogue reveals authentic thinking |
| CV Analysis | **30%** | Documented achievements and skills |
| Motivation Letter | **30%** | Written communication and vision |

### 4 Evaluation Dimensions

| Dimension | What It Measures |
|-----------|-----------------|
| 💪 **Motivation** | Passion, purpose, commitment, drive |
| 🏅 **Experience** | Leadership, projects, outcomes |
| ⚡ **Skills** | Technical ability, communication, problem-solving |
| 🚀 **Potential** | Innovation, growth mindset, scalability |

### Baseline Comparison

| | Manual Review | Simple Rules | **InVisionU** |
|---|---|---|---|
| Scalability | ❌ Hours/candidate | ⚠️ Basic filter | ✅ Real-time |
| Consistency | ❌ Reviewer-dependent | ⚠️ Single dimension | ✅ 4D, reproducible |
| Explainability | ❌ Subjective | ⚠️ Boolean | ✅ Full breakdown |
| Languages | ❌ Reviewer must know | ❌ EN only | ✅ EN/RU/KZ |
| UX | ❌ Submit & wait | ❌ No feedback | ✅ Gamified |

## ✅ Fairness & Ethics

- 🛡️ **Human-in-the-loop** — AI recommends, committee decides
- 🚫 **No demographic bias** — zero racial, gender, or socio-economic data collected
- 🔍 **Explainable AI** — every score includes factor breakdown + feedback
- 🌐 **Multilingual equity** — EN/RU/KZ keyword parity
- 👁️ **Transparent** — candidates see their own scores
- 🔒 **Privacy-first** — no external data transmission, no social media scraping

| No AI text detection | Cannot detect ChatGPT essays | Perplexity/burstiness analysis |
